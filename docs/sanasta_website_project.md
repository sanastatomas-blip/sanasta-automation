# SANASTA.lt internetinio puslapio projektas

## Paskirtis

Šis dokumentas aprašo SANASTA internetinio puslapio kūrimo projektą domenui sanasta.lt.

Tikslas: sukurti aiškų, patikimą ir parduodantį SANASTA puslapį, kuris veiktų kartu su Facebook, LinkedIn, Gmail, CRM, pasiūlymais ir robotų sistema.

Puslapis turi būti ne vizitinė kortelė dėl grožio. Puslapis turi būti pardavimo, pasitikėjimo ir užklausų surinkimo įrankis.

## Pagrindinė pozicija

SANASTA pozicija:

```text
Vienas rangovas. Viena atsakomybė.
Šildymas · Vėdinimas · Oro kondicionavimas.
Sprendimas iš vienų rankų.
```

## Pagrindinė svetainės žinutė

Pirmas ekranas turi pasakyti:

```text
Šildymo, vėdinimo ir oro kondicionavimo sprendimai iš vienų rankų
```

Papildoma eilutė:

```text
Projektuojame sprendimą, montuojame, paleidžiame, prižiūrime ir padedame po įrengimo.
```

CTA:

```text
Gauti pasiūlymą
Užsakyti konsultaciją
Reikia serviso
```

## Svetainės tikslai

Svetainė turi:

- aiškiai parodyti, ką daro SANASTA;
- kelti pasitikėjimą;
- surinkti klientų užklausas;
- nukreipti į tinkamą paslaugą;
- paaiškinti, kodėl SANASTA nėra tik montuotojas;
- parodyti atsakomybę po montavimo;
- susieti su Facebook / LinkedIn turiniu;
- maitinti CRM / Gmail / HubSpot / robotų sistemą;
- paruošti klientą geresniam pokalbiui.

## Pagrindiniai puslapiai

### 1. Pradžia

Tikslas: greitai paaiškinti, kas yra SANASTA ir kodėl verta kreiptis.

Blokai:

- pagrindinė žinutė;
- trys veiklos kryptys: šildymas, vėdinimas, kondicionavimas;
- kodėl SANASTA;
- paslaugų kortelės;
- klientų problemos;
- kaip vyksta darbas;
- forma užklausai;
- kontaktai.

### 2. Šildymas

Turinys:

- šilumos siurbliai oras-vanduo;
- grindinis šildymas;
- sistemos balansavimas;
- paleidimas;
- priežiūra;
- monitoringas;
- tipinės problemos.

CTA:

```text
Noriu šildymo sprendimo
Reikia patikrinti šilumos siurblį
```

### 3. Vėdinimas

Turinys:

- aptarnavimas;
- kvapai / CO2 / oro kokybė.

CTA:

```text
Noriu vėdinimo sprendimo
Reikia pakeisti filtrus / patikrinti sistemą
```

### 4. Oro kondicionavimas

Turinys:

- kondicionierių parinkimas;
- montavimas;
- multi-split sistemos;
- servisas;
- kondensato problemos;
- nuotėkiai;

```text
Reikia serviso
```

### 5. Servisas ir priežiūra

Labai svarbus puslapis, nes čia pinigai ir pasikartojantis darbas.

- gedimų diagnostika;

Turinys:

- Panasonic / Aquarea kryptis;

CTA:

### 7. Darbinis ŠVOK projekto paketas

Strateginis puslapis.

Svarbi riba:


Forma turi būti trumpa ir naudinga.

## Užklausos formos laukai

Minimalūs laukai:

- vardas;
- telefonas;
- el. paštas;
- miestas / objektas;
- paslauga;
- trumpas aprašymas;
- ar turi planą / nuotraukas;
- ar skubu;
- sutikimas dėl duomenų tvarkymo.

Paslaugos pasirinkimai:

- šilumos siurblys;
- grindinis šildymas;
- vėdinimas / rekuperacija;
- kondicionierius;
- servisas;
- monitoringas;
- darbinis ŠVOK paketas;
- kita.

Forma turi kurti SANASTA event objektą ir CRM įrašą.

## Roboto logika puslapiui

Kai ateina forma:

```text
forma -> SANASTA event -> prioritetas -> CRM -> Gmail juodraštis -> next_action -> kalendorius, jei reikia
```

Režimai:

- AUTO: padėkos laiškas / užklausos gavimo patvirtinimas;
- REVIEW: pasiūlymo ar klausimų juodraštis;
- DECISION: kaina, terminas, atsakomybė, garantija, konfliktas.

## Dizaino kryptis

SANASTA vizualas:

- rimtas;
- techniškas;
- juodas / tamsus fonas su oranžiniais akcentais;
- SANASTA logotipas;
- realios darbų nuotraukos;
- mažiau dekoracijų, daugiau aiškumo;
- 70 % vizualo, 30 % teksto, kai naudojama reprezentaciniams blokams;
- pasitikėjimas, ne triukšmas.

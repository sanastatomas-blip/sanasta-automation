# SANASTA | Operacinis centras

## Paskirtis

Šis dokumentas apibrėžia pagrindinį SANASTA kasdienio darbo įėjimo tašką.

Tomas diktuoja faktus balsu arba rašo trumpas žinutes. Sistema turi juos paversti į aiškius įvykius, stalčius, veiksmus, atsakingus asmenis ir terminus.

Tikslas: Tomas neturi pats rūšiuoti chaoso. Tomas diktuoja. Asistentas struktūruoja. Robotai vykdo.

## Pagrindinė taisyklė

Viskas, ką Tomas padiktuoja, turi virsti į vieną iš šių krypčių:

1. Pardavimai / CRM
2. Vykdymas / objektai / kalendorius
3. Pinigai / sąskaitos / skolos
4. Marketingas / Facebook / LinkedIn / Reels
5. Standartai / dokumentai
6. Automatizacija / GitHub / Codex

Jeigu įvykis netelpa į vieną iš šių krypčių, reikia sukurti aiškų paaiškinimą, kodėl jis nestandartinis.

## SANASTA įvykio forma

Kiekvienas diktavimas turi būti paverčiamas į šią formą:

```text
KLIENTAS:
OBJEKTAS:
TEMA:
ŠALTINIS:
KĄ ŽINOM:
KO TRŪKSTA:
RIZIKA:
PINIGAI:
KITAS VEIKSMAS:
ATSAKINGAS:
TERMINAS:
STATUSAS:
```

## Darbo logika

Tomas gali diktuoti neformaliai, netvarkingai, telefonu, objekte ar vairuodamas. Sistema neturi reikalauti tobulo teksto.

Asistentas turi:

1. Ištraukti faktus.
2. Atpažinti stalčių.
3. Suformuoti įvykį.
4. Pasiūlyti kitą veiksmą.
5. Jei įmanoma, atlikti veiksmą naudojant prijungtus įrankius.
6. Jei reikia Tomo sprendimo, aiškiai pažymėti, ko reikia.

## Atsakymo formatas Tomui

Po diktavimo asistentas turi grąžinti trumpą operacinį atsakymą:

```text
SUPRASTA:
- kas įvyko
- kur dedam
- kitas veiksmas

VYKDAU:
- konkretus veiksmas

REIKIA TOMO SPRENDIMO:
- tik jei būtina
```

## Kliento komunikacijos taisyklė

Negalima rašyti klientui bendros žinutės be konteksto.

Kiekviena kliento žinutė turi turėti:

- apie ką kalbėta anksčiau;
- kada siųstas pasiūlymas arba buvo kontaktas;
- ko dabar prašome;
- ką darysime gavę atsakymą.

Standartinė struktūra:

```text
Primenu dėl [objektas / pasiūlymas / darbai].
Kalbėjome [kada].
Dabar trūksta [ko].
Kai gausime [ką], padarysime [ką].
```

## Diktavimo pavyzdžiai

### Pavyzdys 1

Tomas diktuoja:

```text
Įvykis. Mekionis. Panasonic montavimas Ugniakuro 16. Dvi dienos nuo pirmadienio. Reikia pasiruošti medžiagas ir įrašyti į kalendorių.
```

Sistema grąžina:

```text
SUPRASTA:
- Klientas: Mekionis
- Objektas: Ugniakuro 16
- Tema: Panasonic montavimas
- Stalčius: Vykdymas / kalendorius

VYKDAU:
- kuriu kalendoriaus įrašą
- paruošiu medžiagų pasiruošimo sąrašą
```

### Pavyzdys 2

Tomas diktuoja:

```text
Anglakalbis klientas vakar gavo pasiūlymą, bet dar neatsiuntė rekvizitų išankstinei sąskaitai. Parašyk follow-up angliškai.
```

Sistema turi patikrinti kontekstą ir grąžinti:

```text
SUPRASTA:
- Reikia follow-up po vakar siųsto pasiūlymo
- Tikslas: gauti įmonės rekvizitus išankstinei sąskaitai
- Stalčius: Pardavimai / CRM

REIKIA PATIKSLINTI:
- ar tai tas pats anglakalbis klientas iš vakarykščio pasiūlymo?
```

Jeigu klientas aiškus, paruošiamas tekstas su kontekstu.
